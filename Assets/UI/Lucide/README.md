# Lucide icon subset

Source: https://github.com/lucide-icons/lucide
Pinned commit: `91a1359b5ea235f620ba3a9682015ab8d6ada3af`

Selected official SVG icons are retained in `Source~` (excluded from Unity import). The runtime uses 96px transparent PNG exports with white strokes and USS tinting. This avoids an SVG importer dependency and keeps mobile assets small. Licenses: ISC, plus MIT for Feather-derived icons; see LICENSE.txt.
