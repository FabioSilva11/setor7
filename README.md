# Setor7

Unity third-person gameplay project, including the Setor07 UI, gameplay assets, embedded UI packages, and project settings.

## Open the project

1. Install Unity **6000.6.7f1** through Unity Hub.
2. Add this repository's folder as an existing project.
3. Open it and let Unity restore packages and import assets.
4. Open `Assets/Setor07/Scenes/Interface.unity` and press Play. Choose Solo, then JOGAR to load the existing Shooter host session through the loading screen.

The repository includes `Assets` and their `.meta` files, `Packages`, `ProjectSettings`, and project documentation. Unity regenerates `Library`, temporary files, editor-specific state, and IDE projects locally. Build output is excluded.

## Initial backup

The `pre-menu-integration` tag records the project snapshot taken before the menu integration work. This snapshot preserves existing source and asset bytes without line-ending conversion.

See `Assets/Setor07/README.md` for the Setor07 UI documentation.
